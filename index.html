Fintech · Production2022 – now

Simpan Invest: investment app

A production fintech app on iOS and Android that has to stay reliable while shipping often.

Role
Flutter Developer, Feb 2023 – present (intern from Nov 2022)
Stack
  • Flutter
  • BLoC
  • Clean Architecture
  • Fastlane
  • Firebase
  • App Store
  • Google Play
Read the case study: Simpan Invest

Problem

A consumer investment app needs frequent releases on two platforms without regressions, and production issues need to be found before users report them.

What I did

  • Built a Fastlane pipeline that handles build, version increment, signing, and upload, and own Android and iOS releases end to end through Google Play Console and App Store Connect.
  • Integrated the GetStream SDK into the production app on iOS and Android, covering platform setup, permissions, and push notification delivery, verified on both platforms before release.
  • Combined flutter_localization with Firebase Remote Config so in-app copy can change without shipping a new release.
  • Structured features with Clean Architecture (GetIt, use cases), BLoC state, and go_router navigation with deep linking.
  • Used Firebase Crashlytics and Amplitude to locate and prioritise crashes and performance issues in production.

Decisions and constraints

Unit and widget tests with mocked Firebase and BLoC dependencies cover critical user scenarios. I work directly with backend developers on API contracts, auth and session handling, and issue triage.

Outcome

I took the app over from an external vendor's codebase as an intern and now own its mobile release lifecycle.
